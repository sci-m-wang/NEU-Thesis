\chapter{Introduction}\label{chap:introduction}

\section{Background}

NEU-Thesis is a \LaTeX{} thesis template for Northeastern University. It hides most formatting details behind a small set of commands, so authors can focus on the thesis content instead of manually adjusting margins, headers, captions, references, and title pages.

The unified template supports both Chinese and English thesis layouts. Change the language option in \texttt{Thesis.tex} to switch the fixed labels, title-page text, declarations, and sample chapters.

\section{System Requirements}\label{sec:system}

The template should be compiled with \texttt{xelatex}. A full build normally runs \texttt{xelatex + bibtex + xelatex + xelatex} so that citations, the table of contents, and cross references are generated correctly.

For online editing, Overleaf is recommended. For local editing, install a modern \TeX{} distribution such as \TeX{} Live or MiK\TeX{} and use an editor that saves all source files as UTF-8.
